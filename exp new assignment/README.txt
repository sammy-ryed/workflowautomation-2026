ASSIGNMENT 1 - STUDENT PROJECT APPROVAL & ALLOCATION SYSTEM

Start here
1. Read Assignment_1_Report.pdf for the happy path, assumptions, 26 failure paths and notation rationale.
2. View Assignment_1_Diagrams.pdf for eight BPMN diagrams.
3. Open Assignment_1_Complete.bpmn in a BPMN 2.0 editor for editing. Nested subprocess diagram navigation varies by editor; SVG and PNG previews are provided for every diagram.
4. Open Failure_Path_Register.csv in Excel or another spreadsheet editor.

Files
- Assignment_1_Complete.bpmn: semantic BPMN 2.0 XML with eight diagram planes.
- Assignment_1_Diagrams.pdf: vector diagrams, one page per model view.
- Assignment_1_Report.pdf: explanation, policy assumptions, failure register and checks.
- Failure_Path_Register.csv: editable register with exact BPMN IDs.
- *_Diagram.svg: scalable diagram previews.
- Diagram_*.png: image previews generated from the PDF.
- Validation_Summary.txt: actual static checks and limitations.

Only Assignment 1 is included. Deadlines, retry counts and department policy details are proposed modelling assumptions. Add your own student/team details if your submission requires them. The supplied instructor key is not included. The BPMN model is descriptive, not an executable engine configuration.
